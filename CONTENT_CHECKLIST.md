# Kings Rebar: client content checklist

Everything below must be **supplied and approved by Kings Rebar** before the
site is launched or indexed. Until then, each item is a `pending(...)` value (or
an empty list) in `src/content/`. Production builds hide these items, and
development and review builds show them as "Content needed" boxes.

Only the company name, **Kings Rebar**, is confirmed. The following are working
assumptions, **not** facts to publish: that the company operates in or serves
the rebar industry, that the site is business-facing, and that visitors will ask
about products, services or supply.

Please supply wording you are happy to publish verbatim. Avoid claims you
cannot evidence, such as "leading", "largest", "highest quality", years of
experience, tonnage or customer numbers.

## Company and brand

- [ ] Approved logo file (SVG preferred), or confirmation to keep the text wordmark (`site.assets.logo`)
- [ ] Approved browser icon (optional; the current icon is a neutral placeholder)
- [ ] Approved social sharing image, 1200×630 (optional; a typographic image is generated by default)
- [ ] Site language and region, e.g. `en-GB` or `en-IN` (`site.language`)
- [ ] Default site description for search results (`site.siteDescription`)

## Home

- [ ] Optional short line above the main heading (`home.hero.eyebrow`)
- [ ] Introduction, one or two sentences (`home.hero.intro`)
- [ ] Optional hero image showing real Kings Rebar imagery, 1600×1000 (`home.hero.image`)
- [ ] Company overview paragraphs (`home.overview.paragraphs`)
- [ ] Confirm or adjust the short descriptions on the "Explore the site" cards (`home.explore.links`)

## About

- [ ] Introduction (`about.intro`)
- [ ] Company overview (`about.overview.paragraphs`)
- [ ] History, with any dates or milestones checked for accuracy (`about.history.paragraphs`)
- [ ] Values, each with a short description (`about.values.items`)
- [ ] Operating locations or service areas (`about.locations`)

## Products

- [ ] Introduction (`products.intro`)
- [ ] Product list (`products.items`). For each product: name, short summary, and optionally verified specifications (grade, size, standard) and an approved 1200×900 photo
- [ ] Confirm whether stock, availability or pricing should be mentioned at all. It is currently excluded

## Applications

- [ ] Introduction (`applications.intro`)
- [ ] Use cases or industries, each with a short description (`applications.items`)
- [ ] Confirmation that no named projects or clients appear without their permission

## Quality & Responsibility

- [ ] Introduction (`quality.intro`)
- [ ] Quality practices (`quality.sections[0]`)
- [ ] Health and safety (`quality.sections[1]`)
- [ ] Environmental responsibility (`quality.sections[2]`)
- [ ] Standards and certifications. For each one: name, issuing body, scope, and a copy of the current certificate so the date can be recorded in `verifiedOn` (`quality.certifications.items`). No badges or logos are shown until verified artwork is supplied

## Contact and enquiries

- [ ] Public enquiry email address (`site.contact.email`)
- [ ] Public phone number with country code (`site.contact.phone`)
- [ ] Business address, only if it should be public (`site.contact.address`)
- [ ] Business hours (`site.contact.hours`)
- [ ] Map embed URL for the published address, if wanted (`site.contact.map`)
- [ ] Who should receive enquiries, and through which service. This sets `ENQUIRY_WEBHOOK_URL`
- [ ] Confirm the enquiry topics: currently "General enquiry", "Product information", "Supply enquiry", "Other" (`site.enquiry.topics`)
- [ ] **Privacy notice for the enquiry form** (`site.enquiry.privacyNotice`): who receives the data, why, how long it is kept, and how to request deletion. Link to a full privacy policy if one exists. **The form stays disabled in production until this is approved**
- [ ] Wording for the success and failure messages, if different (`site.enquiry.*Message`)
- [ ] Confirmation of whether any named individual (for example a technical contact) should appear on the site. **No individual is named at present**

## Optional

- [ ] Social media profiles to link (`site.social`)
- [ ] Analytics provider and any consent wording it requires (`site.analytics`)

## Launch

- [ ] Production domain (`SITE_URL`)
- [ ] Client sign-off on all copy, product information, contact details, imagery,
      privacy text and any quality or certification statements
- [ ] Then set `ALLOW_INDEXING=true` and rebuild
